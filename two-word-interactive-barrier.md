# A black-box two-word instruction can defeat statistical verification

Add one unit-cost instruction to the ordinary logarithmic-word RAM. On operands $a,b$ it returns the bit $O(a,b)$ of a fixed recursive table. There exists such a table for which a deterministic $T=\Theta(n^2)$-step computation has **no statistically sound interactive proof with worst-case verifier work $o(T)$ and polynomially bounded messages**, even with unbounded prover computation. In the same model $\mathrm{NTIME}[n]\ne\mathrm{DTIME}[n]$. A single universal word choice solves the hard verification problem, so the example does not establish a lower bound on constant-alternation time. It isolates the proposal to obtain a speedup by first building a statistically sound protocol.

At input length $n$ the relevant row consists of the $n^2$ bits $O(n,i)$ for $0\le i<n^2$. On all inputs, let the deterministic computation accept if and only if this row is empty. Its loop reads the entire row. The chosen table will have at most one mark per row. The input bits themselves are immaterial. Word width $12\lceil\log_2(n+2)\rceil$ suffices for both operands and all loop indices.

## The one-change calculation

Consider any interactive verifier on an empty row and fix a prover strategy with acceptance probability $p$. Hold all other rows fixed. For position $i$, let $q_i$ be the probability that the verifier queries the pair $(n,i)$ when playing this strategy. If there are at most $q$ verifier probes, $\sum_i q_i\le q$. Some $i$ has $q_i\le q/n^2$. Insert a single mark there. A cheating prover uses the strategy for the empty row regardless of its own oracle access. Couple the two runs using the same verifier coins. All messages and internal steps agree until that very pair is probed. Hence acceptance on the marked row against this prover is at least $p-q/n^2$. In particular, if $p\ge2/3$ and $q\le n^2/8$, it exceeds $1/3$. This argument permits private randomness and adaptive interaction. It assumes exact soundness against a changed instance in the sense of a bounded probability of false acceptance even on a *single* altered table bit. Interactive proofs of proximity use a different promise on false instances. ## Fixing one recursive instruction for all verifiers

List uniform probabilistic interactive verifier texts with explicit polynomial message, randomness and running-time caps. Repeat every description infinitely often. Truncate each trial to at most $\lfloor n^2/8\rfloor$ probes, rejecting on budget violations. This enumeration covers every proposed subquadratic-work protocol with fixed polynomial communication for all sufficiently large inputs of the final oracle. At a trial choose a fresh length $n$ greater than every first operand fixed at earlier stages and greater than the stage number. Test the verifier on $0^n$, provisionally setting every new row to zero. Under the caps there are finitely many prover information sets and transcripts. Enumerate deterministic prover strategies consistent with the public messages and compute their acceptance probabilities exactly over the private verifier coins. Allowing randomized provers does not increase the maximum.

If the maximum is below $2/3$, keep the row empty. Otherwise insert the single mark given by the calculation. Permanently freeze all rows whose first operand is within the verifier's trial word range, as well as the row just chosen and all smaller unassigned rows. The capped verifier has finite word width at this input length, so this freezes every relevant transcript, including those arising after insertion of the mark. The next trial chooses a larger fresh length. Encoding the width coefficient as part of the verifier description also permits any fixed coefficient for that verifier. Unspecified entries within frozen rows are zero. The freezing frontier grows without bound, and every finite stage is computable by exhaustive search, so the final operation is recursive. For each candidate there are arbitrarily large trials where its truncated protocol violates completeness or soundness. An eventual $o(n^2)$ verifier on the final oracle would agree with the truncated protocol on those sufficiently large trials under the same caps, a contradiction.

The complementary problem has a nondeterministic linear-time decider. Guess one index, range-check it, read $O(n,i)$ and accept on a mark. With native input length available this takes $O(1)$ steps. A deterministic linear-time decider would give a no-interaction proof for emptiness by complementing its output. Thus the same operation witnesses the native class separation. Conversely a universally chosen in-range index suffices to check emptiness in constant time. The separation is for oracle-dependent row languages. The proof gives no relative lower bound for ordinary explicit Boolean SAT, and leaves open a black-box counterexample to the alternating speedup itself. The source model also differs from the bounded-space ordinary computations in the Reingold–Rothblum–Rothblum protocol.
